## What is this package?

This is `discord`, my framework for making Discord bots in Dart.
It's built on top of [nyxx](https://pub.dev/packages/nyxx), and provides a lot of features:

## Features

- Very cool architecture, with plugins (instead of just defining a ton of commands).
- Typed slash commands support (w/ autocomplete!) using build_runner.
- Data storage (w/ SQLite :)
- Permissions systems, like bot owner, bot admin (per server), and customizable permissions for roles (E.G. `tags.delete`).
- Built-in (optional) modlog support, so server admins can log stuff your bot does.
- Built-in support for paginating messages and embeds.
- Support for running multiple bot accounts at the same time.
- Terminal support, including listening for keys pressed, and input.
